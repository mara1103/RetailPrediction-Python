# Pornire interfata Streamlit

1. Deschide un terminal in `dashboard`.
2. Activeaza mediul virtual (venv):
   - PowerShell:
     ```
     .\venv\Scripts\Activate.ps1  sau   C:\Users\Mara\disertatie\dashboard\venv\Scripts\Activate.ps1
     ```
   - Command Prompt (cmd):
     ```
     .\.venv\Scripts\activate.bat
     ```     

3. Porneste aplicatia Streamlit:
   ```
   streamlit run app.py
   ```
